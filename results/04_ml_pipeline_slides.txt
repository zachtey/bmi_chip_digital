----------------------------------------------------------------
  SLIDE: DATASET
----------------------------------------------------------------
  Source   : Brochier et al. — Monkey L neural recordings
             (Blackrock .ns5 broadband + .nev event files)
             Publicly available: G-Node GIN repository
             https://gin.g-node.org/INM6/multielectrode_grasp

  Task     : Classify motor intention from neural activity
  Subject  : Non-human primate (macaque), motor cortex

  4 Classes:
    PG-LF  Power Grasp  — Low Force
    PG-HF  Power Grasp  — High Force
    SG-LF  Skilled Grasp — Low Force
    SG-HF  Skilled Grasp — High Force

  Chance level: 25%  (4 balanced classes)

----------------------------------------------------------------
  SLIDE: SIGNAL PROCESSING PIPELINE
----------------------------------------------------------------
  Step 1 — Raw Acquisition
    30 kHz broadband LFP/spike signal (NS5 Blackrock format)
    Multiple electrode channels (motor cortex array)

  Step 2 — Bandpass Filter
    4th-order Butterworth, 300–3000 Hz
    Preserves spiking band, removes LFP and noise

  Step 3 — Downsample
    30 kHz → 5 kHz  (6:1 decimation)
    Sufficient for 3 kHz signal content (Nyquist)

  Step 4 — ADC Simulation (8-bit)
    Clip to 1st–99th percentile of signal range
    Quantize to 0–255  (simulates chip's SAR ADC)

  Step 5 — Trial Windowing
    50 ms window starting 100 ms after GO cue
    250 samples × 8 channels per trial

  Step 6 — Channel Selection  (Fisher Discriminant)
    Score = between-class variance / within-class variance
    Select top 8 channels from full array
    Maximizes class separability with minimum channels

----------------------------------------------------------------
  SLIDE: SBP FEATURE EXTRACTION
----------------------------------------------------------------
  Formula:
    SBP[ch] = ( Σ |sample - 128| ) >> 8    (over 250 samples)

  Why SBP:
    Approximates neural spiking band power
    128 = ADC midpoint (maps to 0V)
    Absolute deviation ≈ spike energy
    No multipliers — only subtraction + shift
    Maps directly to the hardware accumulator design

  Output: 8 features (one scalar per channel)
          Range: 0–125  (fits in 8 bits)

----------------------------------------------------------------
  SLIDE: MLP ARCHITECTURE
----------------------------------------------------------------
  Network    :  8 → 8 (ReLU) → 4

  Input      :  8 SBP features (one per electrode channel)
  Hidden     :  8 neurons, ReLU activation
  Output     :  4 logits (one per grasp class)

  Parameters :  8×8 + 8 + 4×8 + 4  =  108  total
  Memory     :  108 bytes  (8-bit quantized)
                → fits in scan chain, no SRAM needed

  Why this size:
    Smallest network that empirically separates the 4 classes
    108 bytes loads in ~3,456 scan clock cycles at power-up
    Single shared MAC unit in hardware — no parallelism needed

----------------------------------------------------------------
  SLIDE: TRAINING
----------------------------------------------------------------
  Framework    : PyTorch
  Optimizer    : Adam  (lr = 0.003, weight decay = 1e-3)
  Loss         : Weighted cross-entropy  (handles class imbalance)
  Schedule     : Cosine annealing LR  (500 epochs, min lr = 1e-5)
  Split        : 80% train / 20% test  (random, seed=42)
  Batch size   : 32

  Key design choice — weighted loss:
    Class counts are unequal in the monkey dataset
    Per-class weight = 1/count, normalized
    Prevents network from ignoring minority classes

----------------------------------------------------------------
  SLIDE: QUANTIZATION
----------------------------------------------------------------
  Precision   : 8-bit signed integers  (-128 to +127)
  Method      : Symmetric min-max per tensor

  Key step — Normalization folding:
    Training uses z-score normalization: (x - mean) / std
    At deployment, hardware has no divider
    Solution: fold mean/std into the weight matrix at export
      W_hw = W_float / std
      b_hw = b_float - W_float * (mean / std)
    Hardware receives raw SBP integers — no normalization needed

  Bias scaling:
    Bias and weights quantized independently → different scales
    Two integer correction constants baked into the RTL:
      hidden_bias_scale = 85
      output_bias_scale = 109
    These are fixed hardware parameters, not weights

  Quantization accuracy:
    Float model accuracy  :  see training output
    Quantized model acc   :  see training output
    Target drop           :  < 5%  (verified in pipeline)
    Verification          :  integer golden model matches
                             Verilog cycle-exactly

----------------------------------------------------------------
  SLIDE: HARDWARE DEPLOYMENT BRIDGE
----------------------------------------------------------------
  Output files from bmi_pipeline_final.py:

    weights.hex       108 bytes, hex-encoded, scan chain format
                      Header contains bias_scale constants
                      → loaded into chip at power-up via scan chain

    weights_readable  Human-readable weight matrix dump
                      for debugging / verification

    test_vectors.txt  40 test vectors for RTL sign-off
                      Each vector: ADC samples + expected CLASS[1:0]
                      → used to verify Verilog simulation

    model.pth         PyTorch checkpoint
    preprocessing.npz Selected channels, ADC rails, normalization params

  RTL Verification Flow:
    1. Scan weights.hex into MLP via 864-bit scan chain
    2. Feed ADC samples from test_vectors.txt
    3. Run SBP → MLP → argmax pipeline
    4. Compare CLASS[1:0] to expected — must match exactly
    5. RTL result: 40/40 vectors PASS  ✓

----------------------------------------------------------------
  SLIDE: END-TO-END PIPELINE SUMMARY  (one-liner per stage)
----------------------------------------------------------------

  [Python]
  Raw NS5  →  Bandpass 300–3000Hz  →  Downsample 5kHz
         →  ADC sim (8-bit)  →  Channel select (Fisher)
         →  Window 50ms  →  SBP feature  →  MLP train
         →  8-bit quantize  →  weights.hex + test_vectors

  [Hardware]
  ADC input  →  sample_collection  →  sbp_feature_extraction
           →  mlp_inference  →  argmax  →  SPI output

  Python golden model = Verilog specification.
  The integer-only forward pass in the Python script
  is the exact algorithm the RTL implements.
