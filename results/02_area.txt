----------------------------------------------------------------
  WHY sample_collection IS SO LARGE
----------------------------------------------------------------
  sample_collection stores the full ADC window as flip-flops:

    8 channels × 250 samples × 8 bits = 16,000 flip-flops

  In GPDK045, one DFFRHQX1 ≈ 8.4 µm²
  → 16,000 × 8.4 µm² ≈ 134,400 µm²  (matches the 140,926 µm² cell area)

  To reduce: replace the register file with an SRAM macro
  from a memory compiler. A 2000×8 SRAM would be ~5,000-8,000 µm²
  (15-20× smaller), but requires a memory compiler not included
  in the gsclib045 standard cell library.
